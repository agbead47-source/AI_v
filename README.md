# COSMOA · AI 도구함

우리 조가 직접 조사하고 써본 AI 서비스를 분야별로 모아 둔 웹사이트입니다.
조원은 권한을 받아 서비스를 추가·수정하고, 써본 소감을 남길 수 있습니다.

🔗 **사이트 주소**: https://(내-주소).netlify.app

## 주요 기능

- **분야별 보기** — 6개 묶음, 25개 분야, 107개 AI 서비스 (직접 써본 17개는 `AI_UI.xlsx` 조사 자료, 나머지 90개는 분야별 대표 서비스 조사)
- **검색** — 이름뿐 아니라 하고 싶은 일(자막, 로고, 회의록 등)로도 검색
- **요금 필터** — 무료 / 무료+유료 / 유료
- **직접 써본 것만 보기** — 소감이 달린 서비스만 모아 보기
- **권한별 편집** — 보기 전용 / 조원 / 관리자
- **소감 남기기** — 한 서비스에 조원 여러 명이 각자 소감 작성
- **반응형 · 다크 모드**

### 권한 받는 법 (Netlify 사이트)

1. 사이드바 아래 **편집 권한 받기** (휴대폰은 상단 권한 칩) 누르기
2. 이름과 조장에게 받은 **권한 코드** 입력
3. 이름은 소감 작성자로 표시됩니다

권한 코드는 `js/config.js`에서 바꿉니다. 배포 전에 꼭 바꾸고 조원에게만 알려 주세요.

```js
const CONFIG = {
  MEMBER_CODE: "cosmoa",    // 조원 코드
  ADMIN_CODE:  "admin1234"  // 관리자 코드
};
```

### claude.ai 링크로 공유할 때

권한 코드 대신 공유 설정을 따릅니다. 편집자(Editor)는 관리자, 참여자(Contributor)는 조원, 보기(Viewer)는 보기 전용이며, 수정 내용이 공유 저장소에 저장되어 조원 모두에게 바로 보입니다.

## 서비스 추가하는 법

**화면에서 (조원 이상)** — 상단 **+ 서비스 추가** → 이름·분야 입력 → 추가하기.
기존 서비스는 상세 패널의 **수정** 버튼으로 고칩니다.

**기본 데이터로 넣기** — `js/services.js`의 `RAW`에 한 줄 추가

```js
// [이름, "분야1|분야2", 한 줄 소개, 요금, 주소, 장점, 아쉬운 점, 추천 용도, 사용 방법, 요금 상세, 로고]
["Perplexity", "리서치", "출처를 달아 주는 검색형 AI", "무료+유료", "https://www.perplexity.ai",
 "출처 링크를 같이 보여줌", "무료는 하루 횟수 제한", "과제 자료 찾을 때", "1. 질문 입력
2. 출처 확인", "Pro: $20/월", "perplexity.png"],
```

- 요금은 `무료` / `무료+유료` / `유료` / `확인 필요` 중 하나
- 분야 이름은 `GROUPS`에 적힌 이름과 똑같이
- 장점·아쉬운 점·사용 방법은 `
`으로 줄을 나누면 목록으로, `1. `로 시작하면 번호 목록으로 보입니다
- 로고는 `img/logos/`에 파일을 넣고 파일 이름만 적거나, 이미지 주소를 적습니다. 없으면 이름 첫 글자가 표시됩니다
- 로고 파일은 `https://www.google.com/s2/favicons?domain=사이트주소&sz=128`에서 받을 수 있습니다

## 배포 (Netlify)

1. 이 저장소를 GitHub에 올리기
2. Netlify → **Add new site → Import an existing project** → 저장소 선택
3. 빌드 설정은 비워 두고 **Deploy**
4. 이후 `git push`하면 자동 반영

## 알아 둘 점

- **Netlify 버전의 권한 코드는 진짜 보안이 아닙니다.** 코드가 브라우저에서 보이기 때문에 수업용 편집 잠금으로만 쓰세요.
- **Netlify 버전에서 화면으로 고친 내용은 그 브라우저에만 저장됩니다.** 다른 조원에게 보이게 하려면 `services.js`에 옮겨 push하거나, Firebase 같은 저장소를 연결해야 합니다.
- 서비스 요금과 기능은 자주 바뀌니 공식 사이트에서 다시 확인하세요. 직접 써보지 않은 90개 서비스는 요금 구분만 적고 상세 금액은 공식 요금 페이지 링크로 대신했습니다.
- 써본 서비스는 목록 위쪽에 **써봄** 태그와 함께 먼저 나옵니다. 조원이 써본 뒤 소감을 남기면 자동으로 올라갑니다.
